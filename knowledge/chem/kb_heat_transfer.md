# 传热学知识库

## 导热基础
1. 傅里叶定律：q = -λ·dT/dx，热流密度与温度梯度成正比
2. 导热系数 λ：反映物质导热能力的物性参数，单位 W/(m·K)
3. 热扩散系数 α = λ/(ρ·Cp)，单位 m²/s，反映温度变化传播速度
4. 单层平壁导热：Q = λA(t1-t2)/δ
5. 多层平壁导热：Q = A(t1-tn+1)/Σ(δi/λi)
6. 单层圆筒壁导热：Q = 2πλL(t1-t2)/ln(r2/r1)
7. 多层圆筒壁导热：Q = 2πL(t1-tn+1)/Σ[ln(ri+1/ri)/λi]
8. 导热微分方程：ρCp·∂T/∂t = λ·∇²T + qv
9. 稳态导热：∂T/∂t = 0，温度分布不随时间变化
10. 非稳态导热：温度随时间变化，涉及热惯性
11. 第一类边界条件：给定边界温度 Tw
12. 第二类边界条件：给定边界热流密度 qw
13. 第三类边界条件：给定对流换热系数和流体温度
14. 热阻概念：R = δ/(λA) 或 R = 1/(hA)
15. 接触热阻：两固体接触面间的附加热阻
16. 临界绝缘直径：dc = 2λ/h2，保温层外径小于此值加厚保温反而增大散热
17. Bi = hL/λ，毕渥数，判断内部导热阻力与表面对流阻力之比
18. Bi < 0.1 时可用集总参数法，认为物体内部温度均匀
19. Fo = αt/L²，傅里叶数，无量纲时间
20. 集总参数法：θ/θ0 = exp(-Bi·Fo)
21. 半无限大物体的非稳态导热：误差函数解
22. 无限大平板非稳态导热：分离变量法求解
23. 诺谟图（Heisler Chart）：用于计算非稳态导热
24. 热源法：移动热源的温度场计算
25. 导热形状因子：用于规则形状的导热计算
26. 金属导热：主要依靠自由电子传导热量
27. 液体导热：分子振动传递能量，λ 随温度升高略有下降
28. 气体导热：分子碰撞传递能量，λ 随温度升高而增大
29. 保温材料：多孔结构材料，空气导热系数低，起保温作用
30. 金属的导热系数范围：15-420 W/(m·K)
31. 建筑材料的导热系数范围：0.5-2.0 W/(m·K)
32. 保温材料的导热系数：<0.25 W/(m·K)
33. 水的导热系数：约 0.6 W/(m·K)，高于大多数液体
34. 空气的导热系数：约 0.026 W/(m·K)，是良好的绝热材料
35. 铜的导热系数：约 398 W/(m·K)
36. 铝的导热系数：约 236 W/(m·K)
37. 碳钢的导热系数：约 45 W/(m·K)
38. 不锈钢的导热系数：约 15 W/(m·K)
39. 聚氨酯泡沫的导热系数：约 0.022-0.030 W/(m·K)
40. 岩棉的导热系数：约 0.035-0.045 W/(m·K)
41. 温度对导热系数的影响：一般金属随温度升高而降低
42. 孔隙率对保温材料导热系数的影响：孔隙率越高，λ越小
43. 湿度对保温材料导热系数的影响：含水率上升，λ急剧增大
44. 各向异性材料的导热：不同方向λ不同，如复合材料
45. 导热问题数值解法：有限差分法和有限元法
46. 二维稳态导热数值求解：采用热平衡法建立节点方程
47. 显式格式非稳态导热数值求解：稳定性条件 Fo ≤ 0.5
48. 隐式格式无条件稳定，但计算量较大
49. ADI 交替隐式格式：兼顾稳定性和计算效率
50. 热管：利用相变传热的超高导热装置

## 对流换热
51. 牛顿冷却公式：Q = hA(tw-tf)，定义对流换热系数 h
52. 影响对流换热系数的因素：流速、流体物性、壁面形状、流动状态
53. 流动边界层：速度从 0 变化到主流速度的区域
54. 热边界层：温度从壁温变化到主流温度的区域
55. 边界层厚度 δ 与 δt 之比取决于 Prandtl 数
56. Pr = ν/α，普朗特数，动量扩散与热量扩散之比
57. 层流边界层对流换热系数：h ∝ Re^0.5·Pr^0.33
58. 湍流边界层换热系数：h ∝ Re^0.8·Pr^0.33
59. Re = ρuL/μ，雷诺数，判断流态
60. 临界雷诺数 Rec = 5×10⁵（平板边界层转捩）
61. Nu = hL/λ，努塞尔数，无量纲对流换热系数
62. St = Nu/(Re·Pr)，斯坦顿数
63. Gr = gβΔtL³/ν²，格拉晓夫数，自然对流驱动力
64. Ra = Gr·Pr，瑞利数
65. 管内强制对流层流：Nu = 3.66（恒壁温）或 4.36（恒热流）
66. Gnielinski 关联式：适用于过渡流和湍流
67. Dittus-Boelter 关联式：Nu = 0.023Re^0.8Pr^n
68. Sieder-Tate 关联式：考虑变物性影响
69. 入口段：h 大于充分发展段，入口效应显著
70. 管外横掠单管：Nu = C·Re^n·Pr^0.33
71. 管束换热：顺排和叉排的换热系数不同
72. 叉排管束的换热系数高于顺排
73. 自然对流：Gr·Pr 决定流态和换热强度
74. 大空间自然对流：Nu = C(Gr·Pr)^n
75. 有限空间自然对流：受空间尺寸影响
76. 凝结换热：蒸汽在低于饱和温度的壁面上凝结
77. 膜状凝结：凝结液形成液膜，热阻大
78. 珠状凝结：凝结液形成液珠，热阻小
79. 努塞尔膜状凝结理论：h = 0.943r[gρ²λ³/(μLΔt)]^0.25
80. 水平管外凝结：h 高于竖管
81. 传热强化：增大换热系数或传热面积的方法
82. 翅片管：增加换热面积，提高总传热量
83. 管内插入物：破坏边界层，增强湍流
84. 粗糙表面：促进边界层转捩
85. 纳米流体：添加纳米颗粒增强流体导热系数
86. 微尺度传热：尺度效应显著，连续介质假设失效
87. 沸腾换热：液体在加热面上汽化
88. 核态沸腾：气泡成核、生长、脱离，换热系数大
89. 膜态沸腾：蒸汽膜覆盖加热面，热阻大
90. 临界热流密度 CHF：从核态沸腾向膜态沸腾的转折点
91. 池沸腾曲线：q~Δt 关系曲线，五个区域
92. Rohsenow 关联式：用于核态沸腾换热系数计算
93. 流道中的两相流型：泡状流、弹状流、环状流等
94. 流动沸腾：在流道中流动时的沸腾过程
95. 降膜蒸发：液膜沿壁面流下的蒸发过程

## 换热器
96. 换热器分类：管壳式、板式、翅片管式、螺旋板式
97. 管壳式换热器：最常用，壳程和管程
98. 固定管板式换热器：结构简单，不可热补偿
99. U形管换热器：可热补偿，管束可抽出
100. 浮头式换热器：浮头侧自由膨胀，适应大温差
101. 板式换热器：效率高，占地小，可拆卸
102. 螺旋板式换热器：适用于高粘度流体
103. 翅片管换热器：用于气-气换热
104. 热管换热器：利用相变，传热能力强
105. 套管式换热器：结构简单，小流量适用
106. 平均温差法：Q = KAΔtm
107. 对数平均温差 LMTD：LMTD = (Δt1-Δt2)/ln(Δt1/Δt2)
108. 传热有效度-传热单元数法（ε-NTU 法）
109. 换热器效率 ε = Q/Qmax = (1-exp(-NTU))/(1-Cexp(-NTU))
110. NTU = KA/(mCp)min，传热单元数
111. 热容流率比 C = (mCp)min/(mCp)max
112. 换热器结垢：污垢热阻增加，传热效率下降
113. 污垢系数 Rf：典型值 0.0001-0.0005 m²·K/W
114. 折流板：增加壳程流体湍流，提高换热系数
115. 换热器流动方式：顺流、逆流、交叉流
116. 逆流换热器效率高于顺流
117. 叉流换热器：介于顺流和逆流之间
118. 换热器热力设计步骤：确定热负荷→选型→计算面积→压力降校核
119. 换热器管侧流速推荐值：液体 1-3 m/s，气体 5-30 m/s
120. Bell-Delaware 法：壳程换热系数和压降的精确计算
121. 换热器振动分析：防止管束流体诱导振动
122. 换热器材料选择：耐腐蚀性、强度、导热性
123. 换热器密封：管板与壳体间的密封设计
124. 换热器制造标准：GB/T 151、ASME VIII
125. 换热器压力降计算：管程和壳程分别计算
126. 换热器保温：减少热损失
127. 换热器清洗：机械清洗或化学清洗
128. 换热器腐蚀防护：阴极保护、涂层、材料选择
129. 换热器温度控制：旁路调温、变流量控制
130. 换热器网络优化：夹点技术，最小能耗

## 辐射传热
131. 热辐射：物体因温度而发射电磁波的现象
132. 黑体：理想辐射体，吸收率=1
133. 斯特藩-玻尔兹曼定律：Eb = σT⁴
134. 维恩位移定律：λmaxT = 2897.8μm·K
135. 普朗克辐射定律：黑体光谱辐射力分布
136. 基尔霍夫定律：物体的发射率等于吸收率
137. 实际物体的辐射：α+ρ+τ=1，吸收率+反射率+透射率=1
138. 灰体假设：发射率不随波长变化
139. 角系数：辐射面间几何关系的度量
140. 两黑体间的辐射换热：Q = A1F12σ(T1⁴-T2⁴)
141. 灰体间辐射换热：考虑多次反射和吸收
142. 有效辐射 J = εEb + (1-ε)G
143. 辐射网络法：用电路模拟辐射换热
144. 气体辐射的特点：选择性吸收和发射
145. 辐射遮热板：减少辐射换热的有效方法
146. 太阳辐射常数：约 1367 W/m²
147. 温室效应：玻璃对太阳短波辐射透明，而对长波辐射不透明
148. 火焰辐射：主要来自碳粒子和燃烧产物的辐射
149. 辐射对流耦合：同时考虑辐射和对流换热
150. 耐火材料：耐高温、低热导率的炉衬材料

163. 蓄热器：储存热能，平衡供需
164. 热泵：利用逆卡诺循环将低位热能提升为高位热能
