# 传质学知识库

## 扩散基础
1. 费克第一定律：J = -D·dC/dx，扩散通量与浓度梯度成正比
2. 费克第二定律：∂C/∂t = D·∂²C/∂x²，非稳态扩散方程
3. 扩散系数 D：单位 m²/s，影响传质速率
4. 气体扩散系数：Dgas ∝ T^1.75/P，Fuller-Schettler-Giddings 关联式
5. 液体扩散系数：Dliq ≈ 10⁻⁹ m²/s 量级，比气体小约 10⁴ 倍
6. Stokes-Einstein 方程：D = kBT/(6πμr)
7. 固体扩散系数：Dsolid 远小于气体和液体中的扩散系数
8. 分子扩散：由分子热运动引起的质量传递
9. 对流传质：由流体宏观流动引起的质量传递
10. 传质系数 k：单位 m/s，与对流换热系数 h 类比
11. 舍伍德数 Sh = kL/D，类比 Nu 数
12. Schmidt 数 Sc = ν/D，类比 Pr 数
13. 传质边界层：浓度从壁面浓度变化到主流浓度的区域
14. Chilton-Colburn 类比：jD = jH = f/2
15. Lewis 关系：Le = Sc/Pr = α/D 或 h/Sh = ρCp·Le^(1-n)
16. 等摩尔逆向扩散：NA = -NB
17. 单向扩散：一种组分通过另一种静止组分的扩散
18. 漂流因子：P/(P-pA)，增大传质通量
19. 双膜理论：气液相界面两侧各有一层静止膜
20. 传质阻力叠加：1/K = 1/k + 1/mk'
21. 渗透理论：Higbie 模型，传质系数与接触时间的平方根成反比
22. 表面更新理论：Danckwerts 模型，考虑表面更新的随机性
23. 传质设备效率：级效率、总效率
24. 液滴传质：液滴内部循环增强传质
25. 气泡传质：气泡大小影响气液接触面积

## 吸收
26. 吸收操作：气体混合物中的组分溶解于液体吸收剂中
27. 物理吸收：基于组分在液体的溶解度
28. 化学吸收：溶质与吸收剂发生化学反应
29. 亨利定律：p_i = Eixi 或 pi = Hici
30. 亨利系数与温度的关系：H 随温度升高而增大
31. 气液平衡关系：y_i = mxi，m 为相平衡常数
32. 吸收推动力：Δy = y - y* 或 Δx = x* - x
33. 填料塔：连续接触式气液传质设备
34. 填料类型：拉西环、鲍尔环、鞍形填料、规整填料
35. 板式塔：分级接触式气液传质设备
36. 塔板类型：筛板、浮阀塔板、泡罩塔板
37. 液泛：气速过大导致液相无法正常下流
38. 载点：填料塔操作从持液量稳定到持液量急剧增大的转折点
39. 最小液气比：满足分离要求的最小吸收剂用量
40. 操作液气比：通常取最小液气比的 1.2-1.5 倍
41. 吸收因子法：Kremser 方程计算理论板数
42. 传质单元高度 HTU：衡量传质效率
43. 传质单元数 NTU：衡量分离难度
44. 填料塔设计步骤：物性→平衡关系→液气比→塔径→填料层高度
45. 塔径计算：根据液泛气速确定
46. 板式塔设计步骤：分离要求→理论板数→塔径→塔板结构
47. Fenske 方程：全回流最小理论板数
48. Underwood 方程：最小回流比
49. Gilliland 关联式：理论板数与回流比的关系
50. 解吸操作：与吸收相反，溶质从液相进入气相

## 蒸馏
51. 蒸馏原理：利用混合物中各组分挥发度的差异进行分离
52. 拉乌尔定律：pi = Pi(sat)xi
53. 相对挥发度 αij = (yi/xi)/(yj/xj)
54. x-y 相图：气液平衡关系的图解表示
55. 恒沸物：气液组成相等的混合物，无法用普通蒸馏分离
56. 理论板：离开理论板的气液两相达到平衡
57. 塔板效率：Murphree 气效率 EMV
58. 精馏段操作线：yn+1 = (R/(R+1))·xn + xD/(R+1)
59. 提馏段操作线：ym+1 = (L'/V')·xm - W·xw/V'
60. q 线方程：进料热状态对操作线的影响
61. 泡点进料：q = 1
62. 露点进料：q = 0
63. 汽液混合进料：0 < q < 1
64. 回流比 R = L/D，影响分离效果和能耗
65. 全回流：R = ∞，分离效果最好但无产品
66. 最小回流比 Rmin：达到指定分离要求的最小回流比
67. 最佳回流比：通常取 R = (1.2-2.0)Rmin
68. McCabe-Thiele 图解法：逐板计算理论板数
69. 多组分精馏：多个组分的复杂分离
70. 共沸精馏：加入第三组分改变相对挥发度
71. 萃取精馏：加入溶剂提高相对挥发度
72. 变压精馏：利用共沸组成随压力变化分离
73. 间歇精馏：分批操作，塔釜液不断浓缩
74. 分子蒸馏：在高真空下利用分子平均自由程差异
75. 反应精馏：反应和分离在同一塔中进行
76. 精馏节能技术：热泵精馏、多效精馏
77. 蒸馏操作常见问题：液泛、漏液、雾沫夹带

## 萃取
78. 液液萃取：利用溶质在两相中的溶解度差异
79. 分配系数 Ki = yi/xi
80. 萃取剂选择原则：高选择性、高分配系数、易回收
81. 三角相图：三元体系的图解表示
82. 单级萃取效率较低
83. 多级错流萃取：溶剂用量大
84. 多级逆流萃取：溶剂用量省，效率高
85. 萃取塔类型：转盘塔、脉冲塔、振动筛板塔
86. 超临界萃取：利用超临界流体的高溶解能力
87. 双水相萃取：适用于生物活性物质
88. 固液浸取：固体混合物中可溶组分进入溶剂的过程

## 吸附
89. 吸附：固体表面对流体分子的富集
90. 物理吸附：范德华力作用，可逆
91. 化学吸附：化学键作用，不可逆
92. 吸附等温线：Langmuir、Freundlich、BET
93. Langmuir 方程：q = qm·K·C/(1+K·C)
94. BET 方程：多层吸附理论，用于比表面积测定
95. 吸附剂类型：活性炭、分子筛、硅胶、活性氧化铝
96. 固定床吸附器：操作简单
97. 移动床吸附器：可连续操作
98. 流化床吸附器：气固接触良好
99. 变压吸附 PSA：利用压力变化实现吸附剂再生
100. 变温吸附 TSA：利用温度变化再生

## 膜分离
101. 膜分离原理：利用膜的选择性透过性
102. 膜类型：微滤膜、超滤膜、纳滤膜、反渗透膜
103. 微滤 MF：0.1-10μm，分离悬浮颗粒
104. 超滤 UF：1-100nm，分离大分子
105. 纳滤 NF：0.5-2nm，分离小分子和盐
106. 反渗透 RO：<0.5nm，脱盐
107. 浓差极化：膜面浓度升高导致传质阻力增加
108. 膜污染：颗粒、大分子在膜面沉积
109. 渗透汽化：利用膜的选择性实现液体混合物分离
110. 膜生物反应器：膜分离与生物处理结合

## 干燥
111. 干燥：用热空气去除湿物料中的水分
112. 水分活度 aw：影响微生物生长和化学反应
113. 结合水与非结合水
114. 平衡含水率 X*：物料与一定温湿度空气达到平衡时的含水率
115. 恒速干燥阶段：表面水分汽化控制
116. 降速干燥阶段：内部水分扩散控制
117. 临界含水率 Xc：恒速与降速阶段的转折点
118. 干燥速率曲线：干燥速率随含水率的变化
119. 对流干燥：热空气与物料直接接触
120. 喷雾干燥：将料液雾化成液滴在热风中干燥
121. 流化床干燥：物料悬浮在热空气中
122. 真空干燥：降低压力以降低水的沸点
123. 冷冻干燥：预冻后在高真空下升华
124. 红外干燥：利用红外辐射加热
125. 微波干燥：利用微波加热
