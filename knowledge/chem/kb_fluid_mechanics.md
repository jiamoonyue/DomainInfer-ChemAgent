# 流体力学知识库

## 流体性质
1. 密度 ρ：单位体积流体的质量，kg/m³
2. 粘度 μ：流体抵抗剪切变形的能力，Pa·s
3. 运动粘度 ν = μ/ρ，m²/s
4. 表面张力 σ：液体表面收缩的力，N/m
5. 压缩系数 β = -(1/V)(∂V/∂P)T
6. 体积膨胀系数 α = (1/V)(∂V/∂T)P
7. 牛顿流体：剪切应力与速度梯度成正比
8. 非牛顿流体：幂律模型 τ = K·γ̇ⁿ
9. 假塑性流体：n<1，剪切变稀
10. 胀塑性流体：n>1，剪切变稠
11. 宾汉塑性流体：存在屈服应力 τ₀
12. 粘弹性流体：同时具有粘性和弹性
13. 流体静压力：p = ρgh
14. 静压力分布：在重力场中垂直方向线性变化
15. 帕斯卡原理：作用于密闭流体上的压力等值传递
16. U形管压力计：ΔP = ρgΔh
17. 压力单位：1 atm = 101325 Pa = 760 mmHg = 1.01325 bar
18. 表压、绝压和真空度的关系
19. 大气压随海拔变化：每升高 1000m 约降低 12 kPa

21. 液面下平板上的总压力

23. 浮力定律：阿基米德原理
24. 液位测量：静压法、浮力法、电容法
25. 等压面：静止流体中压力相等的平面

## 流体流动
27. 连续性方程：ρ₁A₁v₁ = ρ₂A₂v₂
28. 伯努利方程：P₁/ρg + v₁²/2g + z₁ = P₂/ρg + v₂²/2g + z₂
29. 实际流体的伯努利方程：包含摩擦损失项
30. 沿程阻力：ΔPf = λ·(L/d)·(ρv²/2)
31. 局部阻力：ΔPj = ζ·(ρv²/2)
32. 达西-魏斯巴赫方程：hf = f·(L/D)·(v²/2g)
33. 莫迪图：摩擦系数 f 与 Re 和相对粗糙度的关系
34. 层流摩擦系数：f = 64/Re（圆管）
35. 湍流摩擦系数：Colebrook 方程求解
36. Blasius 关联式：f = 0.0791Re^(-0.25)
37. 哈根-泊肃叶方程：层流管流压降与流量关系
38. 当量直径 De = 4A/P，非圆管道的折算直径
39. 管件当量长度法：把局部阻力折算为沿程阻力
40. 管路特性曲线：ΔP ~ Q² 关系
41. 并联管路：各分支压降相等，总流量为各支路流量之和
42. 串联管路：各管段流量相同，总压降为各段压降之和
43. 分支管路：流量分配由各分支阻力决定
44. 虹吸管：利用大气压差的输水装置
45. 孔板流量计：节流式流量测量
46. 文丘里管：利用压差测流量
47. 转子流量计：浮力平衡原理
48. 湍流：流体微团不规则运动，Re > 4000
49. 过渡流：Re 在 2300-4000 之间
50. 层流：流线平行，Re < 2300
51. 速度分布：层流抛物线 u/umax = 1-(r/R)²
52. 湍流速度分布：幂律模型 u/umax = (1-r/R)^(1/n)
53. 边界层分离：逆压梯度导致壁面附近流动停滞
54. 绕流阻力：CD·(ρv²/2)·A
55. 卡门涡街：绕流体后交替脱落的旋涡
56. 管内流发展段：入口段到充分发展段
57. 水击现象：阀门突然关闭导致压力急剧升高
58. 空化现象：局部压力低于汽化压力产生气泡
59. 多相流：气液固多相同时流动
60. 气力输送：利用气体输送固体颗粒
