# 环流反应器生物发酵生产 1,3-丙二醇

## 1,3-丙二醇 (1,3-PDO) 概述

1,3-丙二醇（1,3-propanediol, 1,3-PDO）是合成聚对苯二甲酸丙二醇酯（PTT）的关键单体。PTT 纤维具有优异的弹性回复性和染色性能，广泛用于纺织和工程塑料领域。

## 生物发酵法生产 1,3-PDO

### 发酵菌种
工业生产中常用的菌种包括：
- 肺炎克雷伯菌（*Klebsiella pneumoniae*）：以甘油为底物，通过厌氧发酵途径将甘油转化为 1,3-PDO
- 丁酸梭菌（*Clostridium butyricum*）：同样以甘油为底物，厌氧条件下生产 1,3-PDO
- 重组大肠杆菌（*E. coli*）：通过基因工程引入甘油脱水酶基因，以葡萄糖为底物一步法生产 1,3-PDO

### 代谢途径
甘油 → 甘油脱水酶（GDHt）→ 3-羟基丙醛（3-HPA） → 1,3-丙二醇氧化还原酶（PDOR）→ 1,3-PDO

关键辅酶：NADH/NAD⁺ 平衡。副产物包括乙酸、丁酸、乙醇、2,3-丁二醇等。

### 环流反应器在生物发酵中的应用

环流反应器（Air-lift Loop Reactor, ALR）是一种利用气体上升动能驱动液体循环的新型反应器，在生物发酵中具有以下优势：

1. **低剪切力**：气体驱动循环代替机械搅拌，剪切力低，适合微生物细胞的生长和代谢，减少细胞破碎。
2. **传质效率高**：气升式环流设计提供较大的气液接触面积，有利于氧气的溶解和 CO₂ 的排出。
3. **混合均匀**：导流筒设计使发酵液在反应器内形成规则的循环流动，径向和轴向混合均匀。
4. **温度场均匀**：循环流动促进热量传递，避免局部过热导致的酶失活。
5. **能耗低**：无机械搅拌装置，仅需气体压缩动力，运行能耗较传统搅拌反应器降低 30-50%。

### 影响 1,3-PDO 产率的关键因素

1. **底物浓度（甘油浓度）**：甘油浓度过高会抑制菌体生长（底物抑制效应），通常控制在 20-40 g/L。采用分批补料（fed-batch）策略可缓解底物抑制。

2. **产物抑制**：1,3-PDO 浓度超过 60-80 g/L 时对菌体产生明显抑制作用。采用发酵-分离耦合技术（如萃取发酵、膜分离）可在线移除产物，提高产率。

3. **pH 值**：K. pneumoniae 的最适发酵 pH 为 6.5-7.5。pH 过低（副产有机酸积累导致）会抑制甘油脱水酶活性。

4. **温度**：最适发酵温度为 30-37°C。温度过高会导致酶失活，过低则代谢速率下降。

5. **传质特性（气液传质）**：
   - 氧气供应：1,3-PDO 是厌氧发酵产物，其生成过程不需要氧气。微氧条件（DO 0.5-2%）仅用于促进菌体生长和提高甘油消耗速率，但氧气过多会抑制 1,3-PDO 合成途径的关键酶活性。因此氧气不是 1,3-PDO 发酵的必要条件，浓度控制应偏向低氧侧。
   - CO₂ 脱除：环流反应器中 CO₂ 气泡上升驱动循环，同时带走代谢产生的 CO₂，维持适宜溶解 CO₂ 浓度
   - 底物扩散：甘油在水中的扩散系数影响底物向细胞内的传质效率

6. **稀释率**（连续发酵）：环流反应器连续操作时，稀释率 D = F/V（进料流量/反应器体积）。最佳稀释率通常为 0.1-0.3 h⁻¹，平衡底物供给与产物移除。

### 清华大学刘德华教授团队的研究贡献

刘德华教授（清华大学化学工程系，应用化学研究所所长，加拿大工程院外籍院士）团队在 1,3-丙二醇生物炼制领域做了系统研究：

- 建立了甘油发酵生产 1,3-PDO 的完整工艺路线
- 开发了环流反应器用于 1,3-PDO 发酵的放大工艺
- 研究了发酵-分离耦合技术（如双水相萃取、渗透汽化）以缓解产物抑制
- 利用粗甘油（生物柴油副产物）为廉价底物生产 1,3-PDO，降低了原料成本
- 与中石化等企业合作推进了 1,3-PDO 的工业化生产

### 化工计算参考

**产率计算**：
- 理论摩尔产率：1 mol 甘油 → 1 mol 1,3-PDO（不考虑副产物）
- 质量产率：Y_P/S = (76.09 g/mol) / (92.09 g/mol) = 0.826 g 1,3-PDO / g 甘油
- 实际产率：约 0.45-0.65 g/g（受副产物影响）

**甘油消耗速率**：
- 最大甘油消耗速率：约 2-5 g/(L·h)
- 1,3-PDO 生成速率：约 1-3 g/(L·h)

**反应器设计参数**：
- 高径比（H/D）：5-10（环流反应器）
- 气含率（ε_g）：0.05-0.15
- 循环液速：0.2-0.5 m/s
