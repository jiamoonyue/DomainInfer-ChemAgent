# 化工热力学知识库

## 基础概念
1. 系统：敞开系统、封闭系统、孤立系统
2. 状态函数：压力 P、温度 T、体积 V、内能 U、焓 H、熵 S
3. 过程量：热量 Q、功 W，与路径有关
4. 热力学第一定律：ΔU = Q - W
5. 稳定流动能量方程：ΔH + ΔEk + ΔEp = Q - Ws
6. 焓定义：H = U + PV
7. 比热容：Cp（定压）和 Cv（定容）
8. Cp - Cv = R（理想气体）
9. 比热比 γ = Cp/Cv
10. 热力学第二定律：孤立系统熵增原理
11. 熵的定义：dS = δQrev/T
12. 克劳修斯不等式：dS ≥ δQ/T
13. 亥姆霍兹自由能 A = U - TS
14. 吉布斯自由能 G = H - TS
15. 平衡判据：dG = 0（恒温恒压）
16. 化学势 μ_i = (∂G/∂n_i)T,P,nj
17. 相律：F = C - P + 2
18. 理想气体状态方程：PV = nRT
19. R = 8.314 J/(mol·K)
20. 标准状态：298.15 K，1 bar
21. ΔG° = -RT lnK（反应平衡常数）
22. ΔG° = ΔH° - TΔS°

## 状态方程
23. 范德华方程：(P+a/V²)(V-b) = RT

25. SRK 方程：改进的 RK 方程
26. PR 方程：P = RT/(V-b) - a(T)/[V(V+b)+b(V-b)]
27. 维里方程：Z = 1 + B/V + C/V² + ...
28. 压缩因子 Z = PV/(RT)
29. 对应态原理：Z = f(Tr, Pr)
30. Pitzer 偏心因子 ω
31. 对比温度 Tr = T/Tc
32. 对比压力 Pr = P/Pc
